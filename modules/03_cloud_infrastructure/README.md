# Cloud Infrastructure for ML

This module covers cloud platforms and services for machine learning.

## Topics Covered

### 1. AWS SageMaker
- SageMaker Studio
- SageMaker Training
- SageMaker Deployment
- SageMaker Pipelines
- SageMaker Model Monitor

### 2. GCP VertexAI
- Vertex AI Workbench
- Vertex AI Training
- Vertex AI Prediction
- Vertex AI Pipelines
- Vertex AI Model Monitoring

### 3. Azure ML
- Azure ML Studio
- Azure ML Training
- Azure ML Deployment
- Azure ML Pipelines
- Azure ML Model Monitoring

## Getting Started

Each cloud platform has its own directory with examples and demos:

## Prerequisites

- Cloud platform accounts (AWS, GCP, Azure)
- Basic understanding of cloud computing concepts
- Python 3.8+

## Certification Paths

### AWS
1. **AWS Certified Cloud Practitioner**
   - Foundation-level certification
   - Covers AWS cloud concepts, services, security, and billing

2. **AWS Certified Machine Learning - Specialty**
   - Specialty certification for ML on AWS
   - Covers data engineering, exploratory data analysis, modeling, and operations

### GCP
1. **Google Cloud Certified - Cloud Digital Leader**
   - Foundation-level certification
   - Covers GCP cloud concepts, services, security, and billing

2. **Google Cloud Certified - Professional Machine Learning Engineer**
   - Professional certification for ML on GCP
   - Covers ML problem framing, data preparation, model development, and operations

### Azure
1. **Microsoft Certified: Azure Fundamentals (AZ-900)**
   - Foundation-level certification
   - Covers Azure cloud concepts, services, security, and billing

2. **Microsoft Certified: Azure Data Scientist Associate (DP-100)**
   - Associate-level certification for data science and ML on Azure
   - Covers data preparation, model training, deployment, and monitoring
